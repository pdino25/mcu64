# MCU 64 Bracket

A fan-made 64-character Marvel bracket tournament. Pick winners through six rounds, hear each character's theme song, compare characters head-to-head, and crown a champion.

This folder is the whole website: `index.html` plus the `characters` portraits. It needs no build step and runs on any static web host, including GitHub Pages.

## Put it online with GitHub Pages

1. Sign in at https://github.com and click **New** (or go to https://github.com/new).
2. Name the repository (for example `mcu64`), choose **Public**, and click **Create repository**.
3. On the new repository's page, click **uploading an existing file**.
4. Open this `mcu64-site` folder in Finder, select everything inside it (`index.html`, `README.md` and the `characters` folder), and drag it onto the upload area. Wait for all 66 files to finish uploading.
5. Click **Commit changes**.
6. Go to **Settings → Pages**. Under **Build and deployment**, set **Source** to *Deploy from a branch*, pick the **main** branch and the **/ (root)** folder, and click **Save**.
7. Wait a minute or two, then refresh the Pages settings. Your site's address appears at the top, for example `https://your-username.github.io/mcu64/`.

## Updating the site later

Open the repository on GitHub, click **Add file → Upload files**, drag in the changed files, and click **Commit changes**. The site updates within a couple of minutes.

## Notes

- Bracket progress, history and the leaderboard are saved in each visitor's own browser.
- Theme songs play through Spotify's embedded player.
